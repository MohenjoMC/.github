# Mohenjo

Making mods that are actually needed.

Mohenjo is a Minecraft modding organization. We build mods and tools that solve real problems for players and server owners, instead of adding another clutter-crafting-table to the pile.

## Projects

| Repository | What it does | Links |
|---|---|---|
| [Invistags](https://github.com/MohenjoMC/Invistags) | Shows invisible players' nametags and skins at full opacity. Client-side, Fabric. | [Modrinth](https://modrinth.com/mod/invistags) |

More are in the works.

## Getting involved

- Found a bug? Open an issue on the relevant repository.
- Have an idea for a mod that's actually needed? Start a discussion.
- Contributions are welcome. Check each repo's contributing guidelines.
